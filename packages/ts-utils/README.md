> 🧩 A lightweight TypeScript utility library with powerful type helpers and runtime tools.

## ✨ Features

- 🔠 Advanced type utilities (e.g. `Mutable`, `Optional`, `RequireAtLeastOne`)
- ⚙️ Runtime helpers (`omit`, `isInstanceOf`, `asInstanceOf`)
- 🧱 Zero dependencies, written in pure TypeScript (ESM compatible)
- ✅ Fully type-safe & tree-shakable

---

## 📦 Install

```bash
pnpm add @peiyanlu/ts-utils
```
